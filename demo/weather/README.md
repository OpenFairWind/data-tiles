# Meteo@UniParthenope Leaflet demo

This local web application serves the numeric WRF DataTiles frame generated by
`utils/meteouniparthenope2datatiles.py`. Leaflet uses the repository's
`plugins/leaflet` adapter to request exact XYZ-addressed DNT1 payloads, decode
them defensively in the browser, and apply variable-specific palettes. No image
tiles are stored. Domain selection follows the importer metadata for every
zoom. Composite coordinates such as `d01+d02` and `d02+d03` cover the coarser
domain and use finite finer values wherever available, avoiding the rectangular
no-data surroundings produced by a fine-only coordinate set.

Generate the input from the repository root:

```bash
PYTHONPATH=src python utils/meteouniparthenope2datatiles.py \
  'data/meteouniparthenope/files/*.nc' \
  --root ./data/meteouniparthenope/weather-tiles/ \
  --variables U10,V10,T2C,SLP,RH2,DELTA_RAIN,CLDFRA_TOTAL \
  --source-license LicenseRef-MeteoUniParthenope-Terms \
  --source-license-uri https://www.meteo.uniparthenope.it/ \
  --source-attribution "Meteo@UniParthenope" \
  --dataset-license LicenseRef-MeteoUniParthenope-Derived
```

Install the server extra, start the application, and open the displayed URL:

```bash
python -m pip install -e '.[server]'
PYTHONPATH=src python demo/weather/app.py
```

The default input is
`data/meteouniparthenope/weather-tiles/2026/09/07/wrf5_20260907Z1200.mbtiles`.
Override its directory or stem with `DATATILES_WEATHER_DATA_DIR` and
`DATATILES_WEATHER_DATASET`. The source products and this visualization are
uncertified and MUST NOT be used for navigation.
